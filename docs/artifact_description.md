# Artifact description

This artifact combines archived experimental evidence (`results/frozen/`), server and client implementation (`src/`), execution wrappers (`scripts/`), analysis sources (`analysis/`), generated analysis outputs (`outputs/regenerated_analysis/`), and integrity manifests (`manifests/`). The frozen JSON corpus contains 325 results across Core, Core Matched, E1–E7 and archived rerun groups. See [ARTIFACT_MANIFEST.md](../ARTIFACT_MANIFEST.md) for the verified inventory.

Fresh AWS runs require user-supplied datasets, preprocessing artifacts, reachable client instances, and locally edited configuration files. They are not necessary for inspecting the archived results. Start with [AWS_DEPLOYMENT_GUIDE.md](AWS_DEPLOYMENT_GUIDE.md) and [EXPERIMENT_EXECUTION_GUIDE.md](EXPERIMENT_EXECUTION_GUIDE.md).
